# Urban Nest — Real Estate Website

A modern, fully responsive multi-page real estate website. Built as part of my frontend portfolio.

## 🌐 Live Demo
- **GitHub Pages:**  https://ifrakhan0109.github.io/urban-nest/

## ✨ Features
- Property search by location or title
- Filter by property type (House, Apartment, Villa)
- Sort by price (low to high, high to low)
- Dynamic property cards rendering
- Contact form with JavaScript validation
- Modern, clean UI with a responsive design
- Mobile hamburger menu

## 🛠️ Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- JavaScript (Vanilla, ES6)
- Font Awesome Icons
- Google Fonts (Playfair Display, Inter)
